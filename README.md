# Cropstress Compass

Problem statement: Farmers may detect crop stress but still lack reliable information about how quickly the condition could worsen and whether a recommended intervention is likely to help.

Proposed solution: Develop an AI system that analyzes crop-condition history, soil moisture, and weather trends to estimate future stress risk and monitor recovery after intervention.

Research focus: Can combining time-series environmental data with crop observations improve stress forecasting compared with using a single image?

Possible technologies: Python, pandas, scikit-learn, time-series models, and a Streamlit dashboard.
